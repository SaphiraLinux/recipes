# Support

Where to take your question depends on what it is about.

- **Security vulnerabilities**: do not file a public issue. Use the
  private reporting route described in `SECURITY.md`.
- **Reproducible recipe or build bugs**: open a GitHub issue using the
  bug report form.
- **Feature or package requests**: open a GitHub issue using the
  package request form.
- **General upstream software support**: ask the upstream project.
  This repository covers Saphira packaging, not upstream development.
- **Private or commercial support**: see `COMMERCIAL-LICENSING.md`.
